# Honu Docs

Shared documentation tooling for Honu Robotics repositories. One pip
package and one reusable GitHub Actions workflow give every repository the
same result: Markdown sources in `docs/`, a site with the docs.ros.org look
and behavior under Honu branding, one deployed version per branch, and a
version flyout in the lower left to switch between ROS distributions.

This site is itself built and deployed by the tooling it documents.
